## 📌 About The Project

**Codex** is a personal frontend developer portfolio designed to showcase
my skills, projects, achievements, and journey in web development.

The portfolio focuses on creating a clean and modern user interface with
smooth animations, responsive layouts, interactive components, and an
engaging browsing experience across desktop, tablet, and mobile devices.

This project demonstrates my practical understanding of:

- Frontend development
- Responsive web design
- UI/UX implementation
- JavaScript interactions
- CSS animations
- Modern website structure
- Git & GitHub workflow
